# portfolio-files

Big file library for Isaac's portfolio — moved here from the main portfolio repo
so the GitHub Pages site stays under the 1 GB build limit.

## Contents

| Folder | What it is | Size |
|---|---|---|
| `past papers/` | Cambridge IGCSE past papers (question papers + mark schemes) | ~1.3 GB |
| `igcse books/` | IGCSE textbooks (biology, chemistry, physics, economics — split into parts <100 MB) | ~470 MB |
| `igcse things/` | Extra IGCSE resources | ~270 MB |

## Access

This repo is **file storage only** — no GitHub Pages site here (a Pages site would
re-hit the 1 GB limit). Browse the folders on GitHub's web UI, or `git clone`
the repo to download everything.
